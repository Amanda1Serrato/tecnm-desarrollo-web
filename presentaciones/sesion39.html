00–20 min: Fundamentos Teóricos — Observabilidad, Healthchecks y Métricas en Producción

Una aplicación en producción debe exponer su estado interno para que balanceadores y sistemas de monitoreo puedan supervisarla.

01. Endpoint de Salud (`/health` o `/status`)[+]

Ruta estandarizada que verifica la conectividad con la base de datos, memoria disponible y servicios externos.

Devuelve `HTTP 200 OK` si el sistema está operativo o `HTTP 503 Service Unavailable` si hay fallas.
02. Liveness vs Readiness Probes[+]

Liveness: '¿El proceso del servidor está vivo?'. Readiness: '¿El servidor está listo para recibir tráfico y la DB conectada?'.

Estándar utilizado por Kubernetes, Render y AWS para reiniciar contenedores colgados.
03. Métricas de Rendimiento (Latencia P95 / P99)[+]

Monitoreo del percentil de tiempo de respuesta para identificar el 5% o 1% de peticiones más lentas del sistema.

Permite detectar cuellos de botella antes de que afecten a la mayoría de los usuarios.
Invariante de Producción: Una aplicación web profesional debe ser observable, escalable y reproducible en cualquier infraestructura.

Arquitectura de Despliegue y Frontend: Diagnóstico y Profiling en Tiempo Real

Inspección de salud del servicio web:

Estructura JSON de Healthcheck[+]

`{'status': 'healthy', 'db': 'connected', 'version': '1.0.0', 'uptime': 3600}`.

Permite a herramientas como UptimeRobot o Prometheus alertar incidentes en tiempo real.
Profiling de Endpoints Lentos[+]

Uso de middlewares de tiempo para identificar qué consultas de base de datos consumen más de 500 ms.

Guía las optimizaciones de índices y caché en la aplicación.

Antipatrones en Monitoreo Web

Puntos críticos de falla que deben prevenirse en producción y auditarse en las respuestas del LLM:

  • Healthchecks pesados que ejecutan consultas masivas en la base de datos en cada sondeo cada 5 segundos.
  • Retornar HTTP 200 en `/health` a pesar de que la base de datos esté desconectada.
  • Exponer información sensible de infraestructura (versiones exactas de kernels o contraseñas) en el endpoint público de salud.
